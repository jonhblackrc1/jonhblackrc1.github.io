# Iron Mike: la historia de Mike Tyson

Sitio estático de 5 páginas (HTML + CSS + JavaScript vanilla), publicado en
`https://jonhblackrc1.github.io/mike-tyson/`.

| Archivo | Contenido |
|---|---|
| `index.html` | Round 1: historia, línea de tiempo interactiva y cifras |
| `combates.html` | Round 2: carteles de 8 peleas con filtros |
| `familia.html` | Round 3: padres, Cus D'Amato, matrimonios, hijos y homenaje a Exodus |
| `patrimonio.html` | Round 4: gráficos con Chart.js, bancarrota, ingresos y excesos |
| `legado.html` | Round 5: frases, transformación, cultura pop y quiz |
| `styles.css` / `script.js` | Estilos y lógica compartidos |

## Despliegue en GitHub Pages
1. Sube la carpeta `mike-tyson/` a la rama publicada del repositorio `jonhblackrc1.github.io`.
2. En **Settings → Pages**, verifica que la fuente sea esa rama (carpeta raíz).
3. Espera un par de minutos y abre `https://jonhblackrc1.github.io/mike-tyson/`.

## Personalizar
- **Fotos:** reemplaza cada `<div class="ph">` por un `<img>` con licencia (Wikimedia Commons, por ejemplo) y un `alt` descriptivo.
- **Videos:** en `combates.html`, cada tarjeta trae un comentario con el `<iframe>` de YouTube listo para pegar el ID del video.
